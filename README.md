# Tamis Time — Filipino Dessert Calculator

**Tamis Time** is a playful Filipino dessert calculator that generates a final delicacy based on three simple choices. The app includes animations and sound effects to create a great user experience.

## About the App

Tamis Time is designed as a simple interactive calculator. Users go through **three rounds**, each presenting **two options**. After the third choice, the app computes and reveals a Filipino dessert based on the combination.

There are **8 total possible dessert combinations**.

### Features

- **Three‑Step Choice Calculator**  
  Users make three selections, each influencing the final dessert result.

- **Animated Transitions**  
  Smooth animations guide the user from one choice to the next.

- **Sound Effects**  
  Button clicks, transitions, and the final reveal include custom audio feedback.

- **NaN‑Style Calculation Logic**  
  Internally, the app uses a playful “NaN calculator” concept to compute dessert outcomes based on user choices.

---

## How It Works

1. Open the app.  
2. Choose between **two options** in Round 1.  
3. Choose between **two options** in Round 2.  
4. Choose between **two options** in Round 3.  
5. The app calculates your combination.  
6. Enjoy an animated reveal of the Filipino dessert you “created.”  
7. Replay to discover all **8 possible outcomes**.
